# Dental Localizer — Phase 1

Prototype frontend d'une interface de pré-consultation dentaire.

## Lancer le prototype

Le prototype est volontairement simple à lancer : aucune installation npm n'est nécessaire.

1. Décompressez le dossier.
2. Ouvrez `index.html` dans un navigateur moderne.
3. Une connexion Internet est nécessaire pour charger Three.js et les polices Google Fonts depuis leurs CDN.

## Fonctionnalités Phase 1

- Landing/interface professionnelle
- Modèle dentaire 3D manipulable
- Rotation à la souris
- Zoom à la molette
- Sélection de plusieurs zones
- Mise en évidence des zones sélectionnées
- Type de gêne
- Intensité 0–10
- Durée
- Déclencheurs multiples
- Commentaire libre
- Résumé structuré
- Navigation modifier/résumé
- Responsive desktop/tablette/mobile

## Suite logique

Phase 2 pourra remplacer le modèle de démonstration par un modèle dentaire anatomiquement plus détaillé, ajouter les faces dentaires (vestibulaire/palatine/occlusale), améliorer l'accessibilité et préparer les données pour un vrai backend.
